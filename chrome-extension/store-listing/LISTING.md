## Single purpose (שדה חובה בטופס)

```
מציג למשתמש דילים מאליאקספרס שנאספים ומסוננים מראש (הנחה, דירוג, הזמנות),
דרך פופאפ בסרגל הכלים והתראה יומית אופציונלית.
```

## הצדקות הרשאות (Permission justifications - שדה חובה לכל הרשאה)

| הרשאה | הצדקה (להעתקה לטופס) |
|---|---|
| `storage` | שמירת העדפות המשתמש (קטגוריות, שעת התראה) והפיד שנשלף, מקומית במכשיר בלבד. |
| `alarms` | תזמון רענון תקופתי של פיד הדילים ותזמון ההתראה היומית האופציונלית. |
| `notifications` | הצגת ההתראה היומית עם הדיל המוביל, כשהמשתמש הפעיל את האפשרות בהגדרות. |
| `host_permissions` (`https://mobizombi.github.io/*`) | שליפת קובץ ה-JSON הציבורי של פיד הדילים - אין קריאות לכתובת אחרת. |
| `content_scripts` (`https://*.aliexpress.com/*`) | השוואה מקומית בין מזהה המוצר בדף לבין הפיד השמור, כדי להציג תג אם המוצר כבר מופיע בדילים. לא נאסף ולא נשלח מידע מהדף. |

## Data usage disclosure (טאב Privacy practices בטופס)

סמנו **"לא"** (No) לכל קטגוריות איסוף המידע (Personally identifiable
information, Health info, Financial info, Authentication info, Personal
communications, Location, Web history, User activity, Website content) -
התוסף לא אוסף אף אחת מהן.

בתיבת הטקסט החופשית (Data usage disclosure), אפשר להעתיק:

```
תוסף זה אינו אוסף, שומר בשרת, או משתף כל מידע אישי או מידע גלישה של
המשתמש. כל הנתונים (העדפות, פיד דילים) נשמרים מקומית במכשיר המשתמש
בלבד (chrome.storage.local). ההשוואה מול דפי מוצר באליאקספרס מתבצעת
לחלוטין בצד הלקוח, ללא שליחת נתונים לשרת כלשהו.
```

וסמנו את שתי ההצהרות הסטנדרטיות: "I do not sell or transfer user data to
third parties" ו-"I do not use or transfer user data for purposes unrelated
to my item's single purpose".
