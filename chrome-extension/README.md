# מציאון – תוסף Chrome

תוסף Chrome (Manifest V3) שמציג את הדילים מ-[מציאון](https://mobizombi.github.io/alideals-bot/)
- אותו מקור מידע שכבר מזין את הבוט בטלגרם ואת האתר - ישר מסרגל הכלים של הדפדפן.

## למה זה קיים (התכנון בקצרה)

**מטרה עסקית:** לתת סיבה יומיומית לפתוח את "מציאון" (לא רק לגלול פעם ולשכוח), בלי
להיבנות על תלות חדשה בגוגל (Chrome Web Store) ובלי לגעת בפרטיות/בנתונים של המשתמש.

**איך זה עונה על זה:**
1. **באדג' + התראה יומית** - סיבה קונקרטית לחזור כל יום (הדיל הכי חם), לא נודניק כפוי -
   ניתן לכיבוי מלא בהגדרות, ושעה אחת ביום, לא יותר.
2. **פופאפ מהיר** - רואים 30 דילים טריים בלי לצאת מהדף שבו נמצאים.
3. **תג על דפי מוצר באליאקספרס** - אם המוצר שבו צופים כבר נמצא בפיד שלנו, מוצג תג קטן.
   ההשוואה נעשית **מקומית בלבד** מול המידע שכבר נשמר במכשיר; שום דבר לא נשלח לשום שרת.
4. **בלי הרשמה, בלי חשבון, בלי איסוף מידע אישי.**

## מקור הנתונים

`site/build.mjs` כותב `dist/feed.json` - קובץ JSON ציבורי, קליל, בלי סודות (אין בו
מפתחות API), עם עד 60 הדילים הכי טריים. GitHub Pages מגיש את הקובץ הזה עם CORS פתוח,
כך שהתוסף שולף אותו ישירות (`https://mobizombi.github.io/alideals-bot/feed.json`)
בלי שרת ביניים. הקובץ מתעדכן אוטומטית בכל הרצה של ה-workflow הקיים (`post.yml`).

## התקנה (מצב פיתוח / הפצה עצמאית)

1. `node site/build.mjs` (לוודא ש-`dist/feed.json` קיים ומתעדכן - כבר קורה אוטומטית ב-CI).
2. פתחו את Chrome ← `chrome://extensions`.
3. הפעילו **מצב מפתח** (Developer mode, פינה ימנית עליונה).
4. **טעינת תוסף בלתי ארוז** (Load unpacked) ← בחרו את התיקייה `chrome-extension/`.
5. סיימתם - האייקון של מציאון מופיע בסרגל הכלים.

## מבנה

```
manifest.json   Manifest V3: הרשאות מינימליות (storage, alarms, notifications
                + הרשאת host רק לדומיין הפיד; content script רק ל-aliexpress.com)
common.js       קבועים משותפים (כתובת הפיד, קטגוריות, הגדרות ברירת מחדל)
background.js   Service worker: שליפת פיד כל 90 דק', באדג' לדילים חדשים,
                תזמון התראה יומית
popup.html/js/css   רשימת הדילים + סינון קטגוריה
options.html/js/css הגדרות (התראה יומית, שעה, קטגוריות) + הסבר פרטיות
content.js/css  תג קטן על דפי מוצר תואמים באליאקספרס (מקומי בלבד)
icons/          אייקונים (16/32/48/128px, נוצרו פרוגרמטית)
```

## הפצה: המצב האמיתי מול גוגל (חשוב לקרוא לפני שמחליטים)

ביקשתם משהו "בלי הגבלות של גוגל". כדאי להכיר את המגבלה הטכנית (לא רק מדיניות) לפני
שבוחרים איך להפיץ את זה בפועל:

| אפשרות | מה זה נותן | המגבלה |
|---|---|---|
| **Chrome Web Store** | קישור התקנה בלחיצה אחת, עדכונים אוטומטיים, נראות בחיפוש | כפוף לביקורת/מדיניות של גוגל (מוצר תקין כמו זה - התראות דילים עם הפרדה ברורה של קישורי שותפים - עומד בקלות בכללים) |
| **התקנה כ"תוסף בלתי ארוז" (Load unpacked)** | 0% תלות בגוגל, בלי ביקורת | **Chrome המסחרי חוסם לחלוטין** התקנת תוספים לא מה-Web Store למשתמש רגיל, מלבד במצב מפתח - זו לא רק "הגבלת חנות", זו הגנת אבטחה מובנית בדפדפן שלא ניתן לעקוף. לא מתאים לצמיחה של משתמשי קצה - מתאים לצוות הפנימי/בטא טכנית |
| **מדיניות ארגונית (Enterprise policy)** | התקנה אוטומטית + עדכונים, בלי Web Store | דורש שהמחשבים מנוהלים ע"י דומיין/MDM (Google Workspace / Chrome Browser Cloud Management) - רלוונטי לעובדים בארגון, לא לקהל רחב |

**המסקנה הישירה:** אם המטרה היא "שאנשים ישתמשו בזה כל יום" בקנה מידה - **אין דרך
מסחרית לעקוף את חנות האינטרנט של Chrome**. זה לא סעיף במדיניות שאפשר להתחכם לו, זו
התנהגות מוצקה בקוד של הדפדפן. הבנייה כאן נעשתה כך שהתוסף **כשיר לפרסום בחנות** (הרשאות
מינימליות, שקיפות מלאה על קישורי שותפים, בלי איסוף מידע) - כך שאפשר להתחיל בהפצה
ידנית לצוות/בטא, ולהעלות לחנות בהמשך בלי לשכתב כלום.

## פרטיות ואתיקה

- אין איסוף מידע אישי, אין tracking, אין cookie stuffing, אין הזרקת לינקים נסתרת.
- קישורי הדילים הם קישורי שותפים גלויים - בדיוק כמו בבוט הטלגרם ובאתר.
- ההתראה היומית ניתנת לכיבוי מלא בהגדרות; אין push שאי אפשר לעצור.
